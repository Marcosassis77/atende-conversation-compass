# Atende Conversation Compass

# AtendeAI — Fundação do projeto

Quero criar uma plataforma SaaS profissional chamada AtendeAI, voltada para atendimento inteligente de pequenas e médias empresas.

O sistema será uma plataforma de atendimento com inteligência artificial, WhatsApp, CRM e gerenciamento de conversas com clientes.

Nesta primeira etapa, quero construir a estrutura visual e a organização do sistema.

## Identidade visual
- Aparência moderna, profissional e tecnológica.
- Interface limpa e intuitiva.
- Design responsivo para computador, tablet e celular.
- Textos em português brasileiro.
- Evitar aparência de template genérico.

## Estrutura principal

Crie um painel administrativo com menu lateral contendo:

1. Dashboard
2. Atendimento
3. Conversas
4. Clientes
5. Assistente IA
6. Base de conhecimento
7. Relatórios
8. Integrações
9. Configurações
10. Assinatura e plano

## Dashboard inicial

Apresente:
- Total de conversas.
- Atendimentos em andamento.
- Atendimentos concluídos.
- Clientes cadastrados.
- Taxa de resolução pela IA.
- Gráfico de atendimentos por período.
- Atividades recentes.

## Orientações importantes

- Crie uma arquitetura organizada e preparada para crescer.
- Utilize componentes reutilizáveis.
- Prepare a estrutura para futura integração com Supabase, Gemini API e WhatsApp Business Platform.
- Não exponha chaves ou credenciais.
- Não implemente integrações fictícias.
- Não apresente dados de demonstração como se fossem dados reais.
- Não crie botões que aparentem funcionar sem terem funcionalidade.
- Nesta etapa, concentre-se na fundação visual e estrutural.
- Não tente desenvolver todas as funcionalidades de uma vez.

Quero construir um produto SaaS comercial, com qualidade profissional, preparado para atender várias empresas de forma independente e segura.
